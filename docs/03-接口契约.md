# 03 接口契约（Interface Contracts）

> 适用：所有开发者。以下签名定义在 `src/qps/core/ports/`，是跨模块调用的唯一通道。
> 约定：签名即文档；`...` 表示实现体（由开发者实现）；实现禁止改变签名、语义与异常类型。
> 最后更新：2026-08-03

## 1. 契约总则

1. **端口 = Protocol**：所有端口用 `typing.Protocol` 定义，实现类 `struct` 校验（`isinstance` 或 `runtime_checkable`）；
2. **三要素**：每个方法必须满足「前置条件 / 后置条件 / 异常」三要素，见各方法语义；
3. **不可变**：输入输出 DTO 一律不可变（Pydantic `frozen=True` 或 dataclass frozen）；禁止方法内修改传入对象；
4. **幂等**：所有标注「幂等」的方法，重复调用（同一 ID）必须返回等价结果且不产生副作用；
5. **协程语义**：IO 方法一律 `async def`；纯计算方法允许同步；
6. **异常类型**：只抛 01 文档第 7 节定义的类型化异常；
7. **禁止泄漏**：端口实现禁止向上层暴露实现细节（交易所原始对象、内部缓存等）。

## 2. 数据访问端口（DataProviderPort）

```python
class DataProviderPort(Protocol):
    async def get_bars(
        self, instrument_id: str, interval: str,
        start: datetime, end: datetime,
        data_version: str | None = None,
    ) -> list[Bar]: ...

    async def get_ticks(
        self, instrument_id: str, start: datetime, end: datetime,
    ) -> list[Tick]: ...

    async def get_funding_rates(
        self, instrument_id: str, start: datetime, end: datetime,
    ) -> list[FundingRate]: ...

    async def get_open_interest(
        self, instrument_id: str, start: datetime, end: datetime,
    ) -> list[OpenInterest]: ...

    async def get_mark_prices(
        self, instrument_id: str, start: datetime, end: datetime,
    ) -> list[MarkPrice]: ...

    async def get_features(
        self, instrument_id: str, feature_names: list[str],
        start: datetime, end: datetime,
        feature_version: str | None = None,
    ) -> list[FeatureSet]: ...

    async def get_instrument(self, instrument_id: str) -> Instrument: ...
    def calendar(self, exchange: str) -> list[ExchangeCalendar]: ...
```

语义要点：

- 时间范围 `[start, end)` 左闭右开；`start/end` 必填，禁止无边界查询；
- `data_version/feature_version` 为空时返回**当前默认版本**并在结果中标注；
- 数据缺失不抛异常，返回空列表（由调用方判断），但质量 `SUSPECT` 数据默认过滤，除非显式 `include_suspect=True`（需在扩展方法中支持）；
- `get_bars` 返回结果按 `open_time` 升序；重复调用同一参数必须返回一致顺序（确定性要求）；
- `calendar` 返回 `list[ExchangeCalendar]`，按日期升序；字段定义见 docs/02 §3.1。

## 3. Market Adapter 端口（MarketAdapterPort）

```python
class MarketAdapterPort(Protocol):
    async def connect(self) -> None: ...
    async def disconnect(self) -> None: ...

    async def subscribe_bars(self, instrument_id: str, interval: str,
                             callback: Callable[[Bar], None]) -> str: ...
    async def subscribe_funding(self, instrument_id: str,
                                callback: Callable[[FundingRate], None]) -> str: ...
    async def unsubscribe(self, subscription_id: str) -> None: ...

    async def fetch_historical_bars(
        self, instrument_id: str, interval: str,
        start: datetime, end: datetime,
    ) -> list[Bar]: ...

    def status(self) -> AdapterStatus: ...
```

语义要点：

- 回调在事件循环内同步执行，实现方负责去重去抖与缓冲；回调抛异常只记录不中断订阅；
- `subscribe_*` 返回订阅 ID；`unsubscribe` 幂等；
- `fetch_historical_bars` 用于数据采集（分页/限频由 Exchange Adapter 内部处理）；
- `status()` 返回 `AdapterStatus`，字段定义见 docs/02 §3.2。

## 4. Exchange Adapter 端口（ExchangeAdapterPort）

```python
class ExchangeAdapterPort(Protocol):
    async def connect(self, credentials: Credentials | None = None) -> None: ...
    async def disconnect(self) -> None: ...

    async def request(
        self, method: str, path: str,
        params: dict | None = None,
        signed: bool = False,
    ) -> dict: ...

    async def subscribe(self, channel: str, payload: dict,
                        callback: Callable[[dict], None]) -> str: ...

    async def get_server_time(self) -> datetime: ...
    def rate_limiter(self) -> RateLimiter: ...
    def status(self) -> AdapterStatus: ...
```

语义要点：

- 这是**最低层**端口：负责签名、限频、重连、心跳；业务语义（K 线/订单）不在此层；
- `request` 超时后必须抛 `BrokerNetworkError`（禁止静默）；
- 限频触发抛 `BrokerRateLimitError`，调用方按 retry-after 重试；
- 断线自动重连（指数退避，上限可配置），重连后重新订阅全部 channel；
- 所有返回为交易所原始结构（dict），规范化在上一层（Market/Broker Adapter）完成。

## 5. Broker Adapter 端口（BrokerAdapterPort）

```python
class BrokerAdapterPort(Protocol):
    async def connect(self) -> None: ...
    async def disconnect(self) -> None: ...

    async def place_order(self, order: Order) -> OrderAck: ...          # 幂等
    async def cancel_order(self, client_order_id: str) -> OrderAck: ... # 幂等
    async def get_order(self, client_order_id: str) -> OrderStatus: ...

    async def get_account(self) -> Account: ...
    async def get_positions(self) -> list[Position]: ...

    def on_execution_report(self, callback: Callable[[ExecutionReport], None]) -> None: ...
    def on_account_update(self, callback: Callable[[Account], None]) -> None: ...

    def status(self) -> AdapterStatus: ...
```

语义要点（Paper 与实盘实现必须一致）：

- `place_order` 幂等：同一 `client_order_id` 重复调用返回同一订单引用，**不得重复下单**；
- 返回 `OrderAck = {client_order_id, broker_ref, status}`；最终状态通过 ExecutionReport 异步到达；
- `cancel_order` 幂等；订单已成交则返回当前状态；
- `on_execution_report`：注册回调处理成交/状态回报；回调必须可重入（实盘 WS 断线重连后会重放部分回报，实现方需按 `event_id` 去重）；
- 交易所拒单必须抛 `BrokerBusinessError`（含结构化 reject_reason）；
- `get_positions` 返回的 mark price 为 null 时由上层补标价（禁止实盘实现伪造）。

## 6. Feature Pipeline 端口（FeaturePipelinePort）

```python
class FeaturePipelinePort(Protocol):
    def register_feature(self, name: str, func: Callable, input_window: int,
                         params: dict) -> None: ...

    async def compute(
        self, instrument_id: str, interval: str,
        feature_names: list[str], start: datetime, end: datetime,
    ) -> list[FeatureSet]: ...

    async def compute_latest(
        self, instrument_id: str, interval: str, feature_names: list[str],
    ) -> dict[str, float]: ...

    def list_versions(self, feature_name: str) -> list[str]: ...
```

语义要点：

- 特征函数必须是纯函数：`func(bars: list[Bar], params) -> np.ndarray`，禁止 IO；
- **无未来函数校验**：框架校验特征函数只消费截至当前 bar 的数据（按 `open_time` 断言）；
- `compute_latest` 用于实盘关键路径（结果缓存，避免每 bar 全量重算）；
- 特征注册 = 新版本；`register_feature` 相同 name 再次注册视为新版本，旧版本保留。

## 7. 回测引擎端口（BacktestEnginePort）

```python
class BacktestEnginePort(Protocol):
    async def run(self, request: BacktestRequest) -> BacktestRun: ...
    async def run_batch(self, requests: list[BacktestRequest],
                        max_workers: int) -> list[BacktestRun]: ...
    async def rerun(self, run_id: str) -> BacktestRun: ...

def build_backtest_request(
    strategy_version: StrategyVersion,
    params: dict,
    instruments: list[str],
    interval: str,
    start: datetime, end: datetime,
    engine_mode: Literal["VECTORIZED", "EVENT_DRIVEN"],
    cost_config: CostConfig,
) -> BacktestRequest: ...
```

语义要点：

- `BacktestRequest` 全字段显式（数据版本、特征版本、撮合模式、成本配置、杠杆/保证金、随机种子）；
- `run` 返回 `BacktestRun`（status=SUCCEEDED 时含 metrics/trades_ref）；失败必须返回 FAILED 记录而非抛异常；
- `rerun(run_id)`：用原请求原环境重跑，结果必须一致（确定性），差异即 bug；
- `run_batch` 并行执行，`max_workers` 受配置上限约束；单任务失败不影响批次其他任务；
- 成本模型（`CostConfig`）：`{maker_fee, taker_fee, slippage_model(FIXED|DEPTH), slippage_bps, funding_rate_source(REAL|FIXED), leverage, margin_mode, liquidation_margin_rate, use_depth_snapshots}`；
- 事件驱动模式必须输出逐笔交易与权益曲线文件引用；向量化模式输出摘要即可。

## 8. 优化器端口（OptimizerPort）

```python
class OptimizerPort(Protocol):
    async def search(self, request: OptimizationRequest) -> OptimizationRun: ...
    async def stop(self, run_id: str) -> None: ...          # 幂等
    async def status(self, run_id: str) -> OptimizationRun: ...
```

语义要点：

- `OptimizationRequest`：`{strategy_version, search_space(dict), objective(name+weights), algorithm(GRID|RANDOM|BAYESIAN|GENETIC), budget(n_evals), walkforward_config, parallel_workers}`；
- 搜索过程增量写盘（evaluations 实时可查）；`stop` 优雅终止当前 worker；
- 结果必须含 `best_params` 及其样本外（OOS）指标；
- 随机算法必须接受固定 `seed`（可复现）。

## 9. 策略注册表与生命周期端口

```python
class StrategyRegistryPort(Protocol):
    async def save_version(self, code_pack: StrategyCodePack) -> StrategyVersion: ...
    async def get_version(self, strategy_id: str, version_no: int) -> StrategyVersion: ...
    async def list_versions(self, strategy_id: str) -> list[StrategyVersion]: ...
    async def list_strategies(self, status: str | None = None) -> list[Strategy]: ...

class LifecycleManagerPort(Protocol):
    async def transition(
        self, strategy_id: str, target_status: str,
        evidence_refs: list[str], actor: str, reason: str,
    ) -> LifecycleTransition: ...
```

语义要点：

- `save_version` 幂等（同 `content_hash` 返回既有版本，不重复入库）；版本号自动递增；
- `transition` 是状态迁移唯一入口：目标状态非法或无证据 → `ValueError`（带 error_code）；
- 每次迁移写 AuditLog 并广播 `LIFECYCLE_TRANSITION` 事件；
- 证据（evidence_refs）必须是实验/报告/部署 ID，禁止空证据升级到 VALIDATED 及以上。

## 10. 交易链路端口（Signal / Portfolio / Risk / Execution）

```python
class SignalEnginePort(Protocol):
    async def ingest_intent(self, intent: TradingIntent) -> IntentResult: ...

class PortfolioManagerPort(Protocol):
    async def on_intent(self, intent: TradingIntent) -> list[OrderRequest]: ...
    async def get_allocation(self, strategy_id: str) -> StrategyAllocation: ...
    async def get_portfolio_risk(self, account_id: str) -> PortfolioRisk: ...
    async def merge_positions(self, account_id: str) -> None: ...   # 合并同标同向持仓

class RiskEnginePort(Protocol):
    async def pre_trade_check(self, order_request: OrderRequest) -> RiskCheckResult: ...
    async def on_order_update(self, order: Order) -> None: ...
    async def on_market_update(self, event: Bar | Tick | FundingRate) -> None: ...
    async def register_rule(self, rule: RiskRule) -> None: ...
    async def status(self) -> RiskStatus: ...

class ExecutionEnginePort(Protocol):
    async def submit_order(self, order_request: OrderRequest,
                           risk_result: RiskCheckResult) -> Order: ...
    async def cancel(self, deployment_id: str | None = None,
                     instrument_id: str | None = None) -> list[Order]: ...
    async def reconcile(self, account_id: str) -> ReconciliationReport: ...
    async def status(self) -> ExecutionStatus: ...
```

语义要点：

- `ingest_intent`：校验白名单字段、去重限频、有效期检查；拒绝返回 `IntentResult(status=REJECTED, reason)`；
- `on_intent`（Portfolio）：意图 → 一个或多个 `OrderRequest`（仓位合并、精度对齐、余额/权重校验在此完成）；不通过返回空列表 + 原因（不抛异常）；
- `pre_trade_check`：**强制同步语义**（即使 async，也必须在下单前完成）；verdict=BLOCK 时 ExecutionEngine 禁止提交；
- `submit_order`：生成 `client_order_id`、调 Broker 提交；`risk_result` 必须为 ALLOW，否则抛 `RiskBlockError`；
- `reconcile`：本地 vs 交易所快照对比，产出差异清单；差异条目 `{field, local, exchange, action_suggestion}`；
- 全链路（5）中任一拒绝都要产生事件与日志，不允许静默丢弃。

## 11. 策略运行时端口（StrategyRuntimePort）

```python
class StrategyRuntimePort(Protocol):
    async def start(self, deployment: Deployment) -> None: ...
    async def stop(self, deployment_id: str) -> None: ...       # 幂等
    async def restart(self, deployment_id: str) -> None: ...
    async def status(self, deployment_id: str) -> RuntimeStatus: ...
```

语义要点：

- 每个 deployment 独立进程/task；`stop` 后未处理意图作废；
- 启动前执行静态检查（见 04 文档），不通过则启动失败并返回原因；
- `RuntimeStatus`：`{status, heartbeat_ts, last_bar_ts, error_count, last_error}`；
- 崩溃自动重启仅恢复进程，不恢复交易权限（需人工确认，见架构 8.4 节）。

```python
class ExperimentStorePort(Protocol):
    async def create_run(self, run: BacktestRun | OptimizationRun) -> None: ...
    async def get_run(self, run_id: str) -> BacktestRun | OptimizationRun: ...
    async def list_runs(self, strategy_id: str | None = None, run_type: str | None = None) -> list[RunSummary]: ...
    async def compare(self, run_ids: list[str]) -> ComparisonReport: ...

class MonitoringPort(Protocol):
    async def record(self, event: Event) -> None: ...           # 指标/事件
    async def snapshot(self, kind: Literal["account", "position", "portfolio", "system"]) -> None: ...
    async def alert(self, level: str, message: str, context: dict) -> None: ...

class SchedulerPort(Protocol):
    async def schedule(self, job: JobSpec) -> str: ...          # 返回 job_id
    async def cancel(self, job_id: str) -> None: ...
    async def list_jobs(self) -> list[JobStatus]: ...

class AgentGatewayPort(Protocol):                               # M6 占位
    async def submit_task(self, agent_role: str, task_spec: dict) -> TaskRun: ...
    async def read_artifact(self, artifact_id: str) -> Artifact: ...
    async def write_artifact(self, artifact: Artifact) -> str: ...
    async def register_handler(self, agent_role: str, handler: Callable) -> None: ...
```

语义要点：

- `ExperimentStorePort.compare` 输出同构指标并列表格（含 OOS 列）；
- `MonitoringPort.record` 必须非阻塞（异步队列），禁止阻塞交易关键路径；
- `SchedulerPort.schedule`：JobSpec `{job_type, cron|interval, params, timeout, retry_policy}`；任务执行记录 TaskRun；
- `AgentGatewayPort`：M6 实现，MVP 提供本地 handler 占位；Agent 产出 Artifact 不可变，默认只影响 Draft 状态。

## 13. 依赖组装（di.py）

- 提供 `build_container(config) -> Container`，返回各端口实现实例；

- 测试环境通过 `build_test_container()` 注入 mock/内存实现。
