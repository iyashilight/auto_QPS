# 架构决策记录（Architecture Decision Records）

> 本目录记录影响系统设计的决策（ADR）。任何契约变更、设计取舍、需求确认都必须在这里留下记录，方便后续开发者与 AI 追溯「为什么这样设计」。

## ADR 格式

每份 ADR 为独立文件，编号递增：`ADR-NNN-<短标题>.md`，内容包含：

```text
## 状态
已接受 / 已替代 / 已废弃

## 背景
为什么需要这个决策（问题、约束、上下文）

## 决策
具体决策内容

## 影响
对系统的影响（架构、模块、性能、风险）

## 备选方案
考虑过但未采用的选择及原因

## 日期
YYYY-MM-DD
```

## 规则

- 新决策先写 ADR 再实施（或实施后立即补记录，不晚于合入）；
- 决策被替代时，旧 ADR 标记「已替代」并指向新 ADR，不删除；
- Prompt 中要求记录决策时，遵循本格式。
